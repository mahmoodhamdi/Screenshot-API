# Milestone 1.2: Fix JWT Middleware Race Condition

## Status: COMPLETED
## Priority: CRITICAL
## Estimated Effort: Small

---

## Context

The JWT authentication middleware in `src/middlewares/auth.middleware.ts` has a potential race condition in its async flow. The middleware calls `next()` after async operations complete, but if the user lookup fails or the response is sent, there's a risk of `next()` still being called, leading to "headers already sent" errors or undefined behavior.

### Risk Level: HIGH
- Could cause server crashes
- Could lead to authentication bypass in edge cases
- Could cause memory leaks from pending requests

---

## Current State

### The Problem (Lines 119-156 in auth.middleware.ts)

```typescript
export const authenticateJWT = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  try {
    const token = extractToken(req);
    if (!token) {
      throw new AuthenticationError('No token provided');
    }

    const decoded = verifyAccessToken(token);
    if (!decoded) {
      throw new AuthenticationError('Invalid token');
    }

    // ISSUE: Async operation - what if this takes long and request times out?
    const user = await getUser(decoded.userId);
    if (!user) {
      throw new AuthenticationError('User not found');
    }

    if (!user.isActive) {
      throw new AuthorizationError('Account is deactivated');
    }

    req.user = user;
    next(); // ISSUE: next() called after async - race condition possible
  } catch (error) {
    // Error handling...
    next(error); // Both branches call next()
  }
};
```

### Issues Identified

1. **No early return after error responses** - If an error is thrown and handled, `next(error)` is called, but the function continues
2. **No request timeout handling** - Long-running user lookups could leave requests hanging
3. **Cache lookup can fail silently** - If Redis is down, the fallback to DB could be slow
4. **No cancellation on client disconnect** - If client disconnects, work continues

## Requirements

### 1. Fix Async Flow

Ensure proper async/await handling with early returns:

```typescript
export const authenticateJWT = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  try {
    // Early validation
    const token = extractToken(req);
    if (!token) {
      return next(new AuthenticationError('No token provided'));
    }

    const decoded = verifyAccessToken(token);
    if (!decoded) {
      return next(new AuthenticationError('Invalid token'));
    }

    // Check if request was already closed
    if (req.closed) {
      return; // Don't continue processing
    }

    const user = await getUser(decoded.userId);

    // Check again after async operation
    if (req.closed) {
      return;
    }

    if (!user) {
      return next(new AuthenticationError('User not found'));
    }

    if (!user.isActive) {
      return next(new AuthorizationError('Account is deactivated'));
    }

    req.user = user;
    return next();
  } catch (error) {
    return next(error);
  }
};
```

### 2. Add Request Timeout Handling

Add timeout for user lookup:

```typescript
const getUserWithTimeout = async (userId: string, timeoutMs = 5000): Promise<IUser | null> => {
  const timeoutPromise = new Promise<never>((_, reject) => {
    setTimeout(() => reject(new Error('User lookup timeout')), timeoutMs);
  });

  try {
    return await Promise.race([
      getUser(userId),
      timeoutPromise
    ]);
  } catch (error) {
    if (error.message === 'User lookup timeout') {
      logger.warn('User lookup timed out', { userId });
      throw new AppError('Authentication service temporarily unavailable', 503, 'SERVICE_UNAVAILABLE');
    }
    throw error;
  }
};
```

## Implementation Details

### Updated authenticateJWT

```typescript
export const authenticateJWT = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  // Track if we've called next
  let nextCalled = false;
  const callNext = (err?: Error) => {
    if (nextCalled) {
      logger.warn('next() called multiple times in authenticateJWT');
      return;
    }
    nextCalled = true;
    return next(err);
  };

  try {
    const token = extractToken(req);
    if (!token) {
      return callNext(new AuthenticationError('No token provided'));
    }

    const decoded = verifyAccessToken(token);
    if (!decoded) {
      return callNext(new AuthenticationError('Invalid token'));
    }

    // Timeout protection
    const user = await getUserWithTimeout(decoded.userId);

    if (!user) {
      return callNext(new AuthenticationError('User not found'));
    }

    if (!user.isActive) {
      return callNext(new AuthorizationError('Account is deactivated'));
    }

    req.user = user;
    return callNext();
  } catch (error) {
    logger.error('JWT authentication error', {
      error: error instanceof Error ? error.message : 'Unknown error',
      path: req.path
    });
    return callNext(error instanceof Error ? error : new Error('Authentication failed'));
  }
};
```

### Updated authenticateApiKeyMiddleware

```typescript
export const authenticateApiKeyMiddleware = async (
  req: Request,
  res: Response,
  next: NextFunction
): Promise<void> => {
  let nextCalled = false;
  const callNext = (err?: Error) => {
    if (nextCalled) return;
    nextCalled = true;
    return next(err);
  };

  try {
    const apiKeyHeader = req.headers['x-api-key'];
    if (!apiKeyHeader || typeof apiKeyHeader !== 'string') {
      return callNext(new AuthenticationError('API key required'));
    }

    const result = await Promise.race([
      authenticateApiKey(apiKeyHeader, req.ip, req.get('origin')),
      new Promise<never>((_, reject) =>
        setTimeout(() => reject(new Error('API key validation timeout')), 5000)
      )
    ]);

    if (!result.valid) {
      return callNext(new AuthenticationError(result.error || 'Invalid API key'));
    }

    req.user = result.user!;
    req.apiKey = result.apiKey!;
    return callNext();
  } catch (error) {
    return callNext(error instanceof Error ? error : new Error('API key authentication failed'));
  }
};
```
